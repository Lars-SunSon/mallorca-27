# Malle 2027

Abstimmungsseite für einen Kurztrip nach Mallorca im September 2027.
Statisches HTML, kein Build, kein Backend – läuft direkt auf GitHub Pages.

Die Auswahl bleibt im Browser (localStorage) und wird zu einem Text
zusammengebaut, den man per Knopfdruck in die Gruppe schickt.

## Struktur

| Datei | Zweck |
|---|---|
| `index.html` | die komplette Seite, eine Datei |
| `PRODUCT.md` | Rahmenbedingungen und Fakten |
| `DESIGN.md` | Farb-, Typo- und Komponentenentscheidungen |

Preisangaben sind recherchierte Planwerte vom September 2026, keine Angebote.
